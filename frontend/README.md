# Frontend

Blade view, Livewire view và Tailwind CSS 4 cho Ngói Photobooth.

- `resources/views/layouts`: khung trang khách (`app`) và quản lý (`admin`)
- `resources/views/livewire`: giao diện các component Livewire
- `resources/views/errors`: trang lỗi 403, 404, 419, 429, 500, 503
- `resources/css/app.css`: token màu, font (`@theme`) và các lớp dùng chung

Build bằng Vite từ thư mục `backend`: `npm run build` hoặc `npm run dev`.
